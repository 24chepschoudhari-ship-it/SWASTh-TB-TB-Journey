# Deployment

1. Upload all files in this folder to the root of a GitHub repository.
2. Enable GitHub Pages.
3. Open the public Pages URL and test desktop and mobile.
4. Generate a QR code only after the final public URL is fixed.

### Before public release
- Test every role and branch.
- Check all four languages.
- Have the team verify scientific wording against its project documentation.
- Have a TB/diagnostic expert review the final public wording.
- Keep an iGEM AI-use and attribution log.
- Do not claim clinical validity or educational impact without evidence.
