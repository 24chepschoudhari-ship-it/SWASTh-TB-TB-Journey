# SWASTh-TB — The TB Journey
## Phase 8 — True Branching Final

A browser-based educational simulation covering TB awareness, diagnostic literacy and the proposed SWASTh-TB biology.

### Branching
Each decision has four options. Options can lead to different next scenes, with branches later converging so the game remains practical to play.

### Medical framing
The game does not diagnose the player. Symptoms are not treated as proof of TB. Diagnostic testing and clinical evaluation are presented as part of the healthcare pathway. SWASTh-TB is presented as a proposed research concept, not a clinically validated diagnostic.

### Languages
English • Hindi • Marathi • Gujarati

### Run locally
Open `index.html` in a browser.
